# Перефразирование текста поля

Перефразируй другими словами текст поля ввода, с которым сейчас работает пользователь.

Твой ответ подставляется в поле ввода как есть, без обработки. Всё, что не является текстом поля, испортит его значение.

## Входные данные

- Имя поля: `${field_name}`
- Многострочное поле (`is_multiline`): `${is_multiline}`
- Текущее значение поля:

```
${field_value}
```

- Выделенный пользователем текст (если пусто — обрабатывай значение целиком):

```
${selected_text}
```

## Препроцессинг

Ниже приведён JSON-снимок того, что пользователь сейчас видит в IDE: активное окно и открытые диалоги
(заголовки, поля и их значения, флажки, списки, таблицы с видимыми строками, вкладки), признак фокуса
("is_focused": true), активный редактор ("active_editor" — видимая область, выделение, позиция курсора)
и буфер обмена ("clipboard"). Используй его, чтобы понять предметную область и назначение редактируемого поля.

```json
!tool('visual_context')
```

## Порядок работы

1. Определи язык текста.
2. Классифицируй поле по имени "${field_name}" и по визуальному контексту.
3. Проведи комплексный анализ текущего значения поля.
4. Перефразируй текст, используя синонимы и сохранив смысл.
5. Верни перефразированный текст.

## Требования

- Учитывать предметную область (заголовок окна и соседние поля из визуального контекста)
- Перефразировать текст, используя синонимы
- Сохранить смысл
- Вернуть ТОЛЬКО перефразированный текст
- Исключить из результата дополнительные символы, разметку, пояснения, рассуждения
- Не обрамлять ответ символами " ' ` [ ] < >
- Не оборачивать ответ в блок кода (тройные обратные кавычки или тильды) и не применять Markdown-разметку
- Ответ должен начинаться первым символом самого текста поля: без вступлений, пояснений, перечисления вариантов и подсчётов
- Если is_multiline = false, результат должен быть одной строкой
- Если is_multiline = true, результат должен содержать более 10 слов
- Для поля с именем "Имя" результат должен содержать только буквы и цифры
- Для поля с именем "Комментарий" результат должен содержать подробный комментарий
- Для поля с именем "Пояснение" результат должен содержать подробное пояснение
- Язык ответа: ${language} (если текст поля явно на другом языке — сохрани язык текста)

## Пример

Для поля "Пояснение" со значением «Обработка возврата неисправного товара» ожидаемый результат:

Процедура оформления возврата бракованного изделия

Верни только итоговый текст поля.
