# Быстрое исправление проблемы конфигурации

Проект EDT: `${project_name}`.

Выбранные проблемы конфигурации:
```
${configuration_problems}
```

## Порядок работы

1. Вызови `GetMarkers` для проекта `${project_name}` и найди выбранные проблемы по сообщению, `check_id`,
   `source_type`, идентификатору объекта и другим приведённым атрибутам. Не предполагай, что проблема относится
   к открытому сейчас файлу.
2. Исследуй объект конфигурации и окружающий контекст, необходимые для понимания проверки. Если исправление
   неоднозначно или требует изменения бизнес-смысла, сначала объясни это пользователю и запроси решение.
3. Исправь только выбранные проблемы и непосредственно связанные с ними места. Не изменяй несвязанные объекты.
4. Обязательно снова вызови `GetMarkers` для проекта `${project_name}`. Убедись, что выбранные проблемы исчезли
   и исправление не породило новых ошибок. Если проблема осталась, уточни причину, исправь и повтори проверку,
   но не более трёх попыток.
5. Кратко опиши внесённые изменения и результат повторной проверки Configuration Problems.
