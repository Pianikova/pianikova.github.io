# Генерация commit-сообщения

Сгенерируй сообщение для коммита на основе изменений. Следуй следующим правилам написания commit-сообщения.

## Формат вывода
### Изменения одного типа
<краткое резюме изменений>
<пустая строка>
<описание типа> в <область>: <тема>
<описание>

### Изменения нескольких типов
<краткое резюме изменений>
<пустая строка>
<описание типа 1> в <область 1>: <тема1>
<описание 1>
<пустая строка>
<описание типа 2> в <область 2>: <тема 2>
<описание 2>
<пустая строка>
<описание типа 3> в <область 3>: <тема 3>
<описание 3>
...

## Справочник типов изменений
| тип      | описание типа          | область               |
| -------- | ---------------------- | --------------------- |
| feat     | Новая функциональность | user, payment         |
| fix      | Исправление ошибки     | auth, data            |
| docs     | Документация           | README, API, comments |
| style    | Стиль кода             | formatting            |
| refactor | Рефакторинг кода       | utils, helpers        |
| perf     | Производительность     | query, cache          |
| test     | Тестирование           | unit, e2e             |
| build    | Система сборки         | webpack, npm          |
| ci       | CI конфигурация        | Travis, Jenkins       |
| chore    | Прочие изменения       | scripts, config       |
| i18n     | Интернационализация    | locale, translation   |

## Пример commit-сообщения

```
Код был значительно оптимизирован, добавлена новая функциональность и исправлен стиль

Рефакторинг кода в SSL/src/Documents/ЭлектронноеПисьмоИсходящее/ObjectModule.bsl: оптимизация проверки параметров
- удалена избыточная проверка
- улучшена производительность и читаемость кода

Новая функциональность в SSL/src/CommonModules/MyModule/Module.bsl: вычисление факториала
- реализована функция расчета факториала
- используется простой метод вычисления
- необходимо добавить проверку параметров
```

## Входные данные

Текущий diff:

```
!tool('git_diff')
```

Последние commit messages:

```
!tool('git_recent_commits')
```

Дополнительный ввод пользователя:

```
${user_text}
```

Верни только текст commit message.
