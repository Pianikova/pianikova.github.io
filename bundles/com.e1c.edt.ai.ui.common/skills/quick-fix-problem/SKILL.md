# Быстрое исправление проблемы

Исправь указанную проблему в файле проекта и подтверди результат повторной проверкой маркеров.

## Входные данные

- Файл: `${absolute_file_path}`
- Строка: `${line}`
- Проблемы, которые нужно исправить:

```
${problem_messages}
```

## Порядок работы

1. Прочитай инструментом `Read` текущее содержимое файла `${absolute_file_path}` вокруг строки `${line}` (±20 строк) — выделенный фрагмент сам по себе не даёт достаточного контекста для корректного исправления.
2. Исправь **только** указанную проблему (и другие проблемы из списка выше, если они относятся к той же строке). Не изменяй несвязанный код, не переформатируй файл.
3. Примени правку инструментом `Edit`.
4. **Обязательно проверь результат**: вызови инструмент `GetMarkers` для файла `${absolute_file_path}` и убедись, что исправленная проблема исчезла и правка не породила новых ошибок. Если проблема осталась или появились новые — исправь их и проверь `GetMarkers` ещё раз (не более 3 попыток).

## Формат вывода

Кратко (1–2 предложения) опиши, что изменено и почему, и подтверди результат проверки маркеров.
