# Руководство по исправлению ошибок

## Задача

Предложить свой вариант текста.

## Входные данные

JSON-структура с полями, где одно из полей находится в фокусе (is_focused: true).

## Требования к обработке

- Учитывать предметную область
- Проанализировать JSON-структуру со всеми полями
- Проанализировать значение поля, которое находится в фокусе
- Предложить свой вариант текста
- Исключить из результата дополнительные символы, разметку, пояснения, рассуждения
- Не обрамлять ответ символами " ' `
- Если is_multiline: false, то в ответе должна быть только одна строка
- Значение поля с именем "Имя" ("name": "Имя") должно содержать только буквы и цифры
- Значение поля с именем "Пояснение" ("name": "Пояснение") должно быть развернутым
- Значение поля с именем "Комментарий" ("name": "Комментарий") должно содержать подробные комментарии

## Алгоритм работы

- Проанализировать всю JSON-структуру
- Определить язык
- Найти поле с параметром is_focused: true
- Предложить текст для поля с параметром где is_focused: true

## Примеры

Для входного текста:

```json
{
  "groups": [
    {
      "title": "Основные",
      "fields": [
        {
          "name": "Имя",
          "value": "ОбработкаВозврата",
          "is_focused": false,
          "is_multiline": false
        },
        {
          "name": "Синоним",
          "value": "Обработка возврата неисправного товара",
          "is_focused": false,
          "is_multiline": false
        }
      ]
    },
    {
      "title": "Представление",
      "fields": [
        {
          "name": "Пояснение",
          "value": "",
          "is_focused": true,
          "is_multiline": true
        },
        {
          "name": "Расширенное представление",
          "value": "",
          "is_focused": false,
          "is_multiline": false
        }
      ]
    }
  ],
  "title": "Обработки→ОбработкаВозврата→Основные"
}

```

Ожидаемый результат:

Выполняет обработку просроченных товаров
