# Юлия Пьяникова

Официальный сайт российской скрипачки Юлии Пьяниковой.

[Открыть сайт](https://pianikova.github.io/)

На сайте собраны:

- биография;
- творческие проекты;
- репертуар;
- концертная афиша и архив выступлений;
- видео и фотографии;
- материалы для прессы и организаторов;
- актуальные контакты и социальные сети.

Сайт доступен на русском и английском языках и поддерживает установку как приложение.

Проектная и техническая документация находится в разделе [docs](./docs/README.md). История дизайн-концепции собрана отдельно в разделе [concept](./concept/README.md).
