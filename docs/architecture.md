# Архитектура

## Состав решения

- `src/Pianikova.Web` — клиентское приложение Blazor WebAssembly;
- `build` — консольное приложение с целями сборки, проверки контента и публикации;
- `content` — редакционные данные и медиаресурсы;
- `cloudflare/decap-oauth` — OAuth-посредник для встроенного редактора;
- `cloudflare/telegram-feed` — webhook для Telegram и публичный API ленты;
- `.github/workflows` — CI и публикация GitHub Pages.

Приложение использует .NET 10, Blazor WebAssembly и Pure.DI. Markdown обрабатывается библиотекой Markdig; встроенный HTML в редакционных Markdown-полях отключён.

## Источники данных

При локальном запуске приложение читает синхронизированную копию каталога `content` из собственного web-root.

Опубликованное приложение включает каталог `content` в сборку и читает его с адреса сайта:

```text
https://pianikova.github.io/content/
```

Изменения, сохранённые через `/admin` в ветку `main`, автоматически запускают повторную публикацию сайта. После её завершения обновлённый контент доступен посетителям.

Журнал читает подготовленные файлы `content/telegram/journal` (см. [Журнал Telegram](./telegram-journal.md)) тем же способом, что и остальной контент.

Лента Telegram загружается отдельно из Cloudflare Worker. Worker принимает новые публикации канала, оставляет только сообщения со ссылкой на `pianikova.com` и хранит результат в D1. Браузер повторно запрашивает ленту раз в пять минут, пока вкладка видима. Адрес API указан в `content/settings/site.json`.

## Маршруты

- `/` — публичная страница;
- `/journal` — журнал Telegram-канала: лента выпусков, поиск, фильтр по годам и рубрикам;
- `/journal/{id}` — выпуск журнала;
- `/admin` — вход в редактор;
- `/admin/site` — главная страница, биография, репертуар, проекты, пресса и контакты;
- `/admin/schedule` — концерты;
- `/admin/videos` — видео;
- `/admin/photos` — фотографии.

## Локализация

Редакционный контент физически разделён между каталогами `en` и `ru`. Интерфейсные подписи хранятся в:

- `src/Pianikova.Web/Resources/Ui.resx` — английский язык;
- `src/Pianikova.Web/Resources/Ui.ru.resx` — русский язык.

Язык выбирается по параметру `lang`, сохранённой настройке браузера или его языку. Поддерживаемые значения задаются в `content/settings/site.json`.

## Отображение секций

Публичная страница строится по данным: пустые секции, ссылки и элементы управления не выводятся. Поэтому удаление данных в редакторе скрывает соответствующую секцию без изменения кода.
