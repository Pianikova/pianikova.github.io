# Встроенный редактор

Редактор является частью приложения и доступен по адресу `/admin`. Отдельная CMS не используется.

## Вход

1. Открыть `http://localhost:5188/admin` локально или `https://pianikova.github.io/admin` на опубликованном сайте.
2. Нажать кнопку входа через GitHub.
3. Использовать GitHub-аккаунт с правом записи в репозиторий сайта.

Обмен OAuth-кода на токен выполняет Cloudflare Worker. Его настройка описана в [отдельной инструкции](../cloudflare/decap-oauth/README.md). Секрет GitHub OAuth нельзя хранить в репозитории.

## Разделы

- **Главная страница** — идентичность, изображения, биография, репертуар, проекты, пресса и контакты;
- **Расписание концертов** — будущие и прошедшие события;
- **Видео** — выбранное исполнение и дополнительные записи;
- **Фото** — изображения и подписи.

Общие системные поля показываются один раз. Переводимые поля редактируются отдельно для English и Русский. Поля с длинным текстом поддерживают Markdown там, где это указано в интерфейсе.

## Сохранение

Редактор сохраняет изменения непосредственно в ветку `main`. Опубликованный сайт читает контент из GitHub во время работы, поэтому отдельного черновика или шага публикации контента нет.

Локальный `/admin` также работает с настоящим репозиторием, а не с изолированной тестовой копией. Перед сохранением следует внимательно проверить обе языковые версии.

## Пустые данные

Если раздел не должен отображаться, нужно удалить его данные, но не код приложения. Пустые секции и связанные с ними пункты меню скрываются автоматически.

Коллекция статей пока не поддерживается ни редактором, ни публичным сайтом. Для её добавления потребуется единое изменение модели, отображения и административного интерфейса.
