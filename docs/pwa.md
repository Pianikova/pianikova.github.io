# Установка как приложение (PWA)

Сайт поддерживает установку в Google Chrome и других Chromium-браузерах на компьютерах и телефонах.

## Состав

- `src/Pianikova.Web/wwwroot/site.webmanifest` — имя, область запуска, режим окна и иконки;
- `app-icon.svg` — векторный исходник и favicon;
- `app-icon-192.png` и `app-icon-512.png` — установочные иконки Chrome;
- `app-icon-maskable-512.png` — maskable-иконка Android;
- `service-worker.js` — регистрация приложения, offline fallback и сетевой кеш.

Service worker использует network-first стратегию. Это важно для Blazor WebAssembly и редакционного контента: браузер сначала пытается получить актуальный ресурс и использует кеш только при отсутствии сети.

## Установка

После публикации по HTTPS Chrome показывает действие установки в адресной строке или меню браузера. `localhost` также считается безопасным контекстом и подходит для локальной проверки.

## Проверка в Chrome

1. Открыть сайт.
2. Открыть Chrome DevTools → **Application**.
3. Проверить **Manifest**: имя, `start_url`, `standalone`, иконки 192×192 и 512×512.
4. Проверить **Service Workers**: worker активирован и контролирует страницу.
5. Выполнить установку через адресную строку или меню Chrome.

При изменении service worker необходимо менять имя кеша, чтобы старые ресурсы были удалены при активации новой версии.
